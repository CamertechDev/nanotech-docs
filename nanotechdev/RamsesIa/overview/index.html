RAMSES IA — Vue d'ensemble

Statut : 🟡 Produit Public en cours de mise en service Cloud Run​

RAMSES IA (marque produit Ramsess-AI) est l'offre grand public. Ce n'est pas RAMSES RAG.

Le visiteur ouvre un chat dans le navigateur, s'inscrit, consomme un forfait de messages par jour, et parle à un modèle open source hébergé sur une VM GPU NaNo-IA. Il n'y a pas de notebook, pas de bibliothèque documentaire, pas de RLS tenant.

Sources internes : docs/pUBLIC/*, AGENT-PUBLIC-INSTRUCTIONS.MD, src/ApiPublic, src/BlazorWasmRag.Public.

Frontière avec RAMSES RAG​

RAMSES RAGRAMSES IA (Ramsess-AI)
ClientEntreprise, installé chez le client ou SaaS B2BGrand public, SaaS
CodeApiRag + BlazorWasmRag.EnterpriseApiPublic + BlazorWasmRag.Public
DonnéesPostgres du client / Neon Entreprise (neondb, rôle nanoia_app)Neon Public (base nanoia, rôle apipublic_app)
ChatDirect ou vase RAG (sources + citations)Chat seulement
Inférenceollama-gpu-vm (souvent Qwen 14B)Même VM GPU, modèles Public (chat, vision)
DéploiementCompose sur VM RAG, ou Cloud Run EntrepriseCloud Run nanoia-public + nanoia-public-web
AdminOperator ApiRag + Admin tenantConsole /operator ApiPublic, propriétaire distinct
PaiementLicence JWTForfaits + CinetPay (sandbox / stub selon env)

Un même GPU peut servir les deux. Les bases, cookies, comptes et buckets d'export ne se mélangent pas.

Ce qui est déjà livré (code)​

  • Chat streamé, historique local, langue par défaut français.
  • Composeur multimodal : texte, image, caméra, dictée Whisper, pièces jointes Office.
  • Compte visiteur : e-mail, Google, Microsoft, téléphone.
  • Forfaits, quotas, Fair Use, console opérateur, invitations, reset mot de passe admin.
  • Exports Word / PowerPoint / PDF vers un bucket GCS Public.
  • Pipelines migrate-neon-public.yaml et deploy-public.yaml.

Ce qui reste à valider sur l'environnement cible (Cloud Run + Neon + GPU) porte le statut PARTIEL dans les journaux de prompts. Un build local ne suffit pas à écrire VALIDE.
