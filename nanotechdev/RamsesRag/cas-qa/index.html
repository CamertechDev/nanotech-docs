Cas QA

Statut : 🟡 Protocoles rédigés — exécution navigateur / Compose / Cloud Run à consigner​

Index issu de docs/USEACSE-ENTREPRISE.MD et des fichiers docs/entreprise/USE-CASE-QA-*.md. Cette page est la recette Enterprise. Elle ne mélange pas la campagne Public.

Le statut VALIDE exige l'environnement cible (Compose, VM client ou Cloud Run), pas seulement un build.

Prérequis communs​

  • ApiRag + Enterprise de la version à tester ;
  • PostgreSQL de recette (pas Neon depuis un poste d'agent) ;
  • Ollama ou équivalent pour les cas d'inférence ;
  • comptes : Operator, propriétaire Admin, Admin délégué, Membre, Support temporaire ;
  • fichiers de recette sans donnée personnelle ;
  • aucune preuve contenant mot de passe, code d'activation, cookie, prompt ou document client.

Hors recette (non finalisé)​

Cache sémantique, accusé obligatoire des politiques bloquantes, canvas graphique de carte mentale, persistance des claims features, SqlAgent, contexte statique, agents outillés. Prompts 26 à 31 : hors campagne tant que leur journal n'est pas TERMINE.

Ordre de campagne​

  1. Identité et licence (ID-01, P17-01).
  2. Calebasse / vase / sources / chat / Studio (CAL, VAS, SRC, NCH, STD).
  3. Import fichiers et pièces jointes (P13, P21, P18).
  4. Console Admin (ADM).
  5. Écran Support (SUP).
  6. Garde-fous GPU.
  7. Operator (P20) si la console HTML est dans la release.

Minimum Calebasse/vase : CAL-03, CAL-06, SRC-01, SRC-06, SRC-07, NCH-01, NCH-02, STD-02, STD-05, VAS-04.

Minimum GPU : GPU-01, GPU-02, GPU-04, GPU-12, GPU-16.

Console Admin (/parametres)​

Protocole : USE-CASE-QA-CONSOLE-ADMIN.md. Rôle Admin seulement. Membre et Support : refus API, pas seulement masquage UI.

Surfaces : Utilisateurs, Départements, Sessions, Politiques, Contrat, Analytique. Service TI : impossible à renommer ou supprimer. Invitations : siège réservé, y compris codes en attente. Propriétaire : seul à nommer / rétrograder un Admin délégué.

Support (/plateforme)​

Protocole : USE-CASE-QA-ECRAN-SUPPORT.md. Compte temporaire créé par l'Operator (durée 1–72 h, défaut 8 h). Ne consomme aucun siège. Pas d'accès aux documents privés.

ThèmeContrôle
ChunkingSupport enregistre Recursive / taille ; Admin n'a pas le formulaire (P2-01).
FormatsCases = lecteurs réellement implémentés.
IsolationTenant d'un autre client → 404.
TransparenceBannière Admin : un accès Support est ouvert.

Garde-fous GPU​

Protocole : USE-CASE-QA-GARDE-FOUS-GPU.md.

Pas de facture au jeton. Un utilisateur trop rapide : 429. Un PDF trop long : coupé. Un fichier trop lourd : 413. La ligne de jetons dans le chat est un budget de fenêtre.
