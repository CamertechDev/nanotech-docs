## Ouvrir le Profil

Onglet **Clients** → icône **Profil** (en haut à droite), ou navigation depuis le menu selon votre appareil.

---

## Modifier mon profil

**Modifier mon profil** :

| Élément | Usage |
| --- | --- |
| Logo | Apparaît sur vos PDF |
| Téléphone, adresse | Coordonnées entreprise |
| IBAN | Factures (optionnel) |
| Langue interface | Français par défaut |

---

## Mes disponibilités

Horaires de travail, adresses de **départ** et de **retour**, jours off — utilisés pour le planning (formule Pro).

Congés : section **Indisponibilités** pour bloquer des dates.

---

## Mes tarifs fournisseurs (Pro)

Catalogue de vos prix négociés (chauffe-eau, PAC…). Alimente le **devis vocal** quand le produit est reconnu.

Accès : **Profil → Mes tarifs fournisseurs** ou menu dédié selon votre formule.

---

## Mon abonnement

Consultez votre formule actuelle (**Essai**, **Base**, **Professionnel**).

Sur web et Android : comparatif des formules et simulation de changement (MVP sans paiement en ligne).

Sur **iPhone/iPad** : informations sans prix — contactez le support pour changer de formule.

## Supprimer mon compte et mes données

En bas du Profil : lien rouge **Supprimer mon compte et mes données**.

:::danger Action définitive
La suppression efface **tout** : clients, devis, factures, chantiers, fichiers (logo, PDF, enregistrements) et votre accès ArtDevis. **Irréversible.**
:::

Parcours :

1. Premier dialogue d'avertissement → **Continuer**
2. Confirmation finale → **Supprimer définitivement**
3. Retour automatique à l'écran **Connexion**

:::warning Patron avec équipe
Retirez d'abord tous les membres **actifs** via **Mon équipe** → **⋮ → Retirer de l'équipe**.
:::

Les opérateurs suppriment leur propre compte depuis leur appareil.
