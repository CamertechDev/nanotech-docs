## Principe

Votre **client n'utilise pas ArtDevis**. Vous lui envoyez le **PDF** par WhatsApp, email ou SMS, puis vous suivez la réponse dans l'application.

```
Devis vocal → PDF → Partage au client
       ↓
Marquer envoyé (optionnel)
       ↓
Client répond (téléphone, WhatsApp…)
       ↓
Accepté ou Refusé dans l'app
       ↓
Si Accepté → Mes Chantiers
```

---

## Partager le PDF

| Moment | Comment |
| --- | --- |
| Juste après le devis vocal | Écran PDF → **Partager** |
| Plus tard | Fiche client → **Historique devis** → **Partager PDF** |

Le PDF est régénéré à chaque partage si vous avez modifié le devis.

---

## Suivre le statut du devis

Sur la **fiche client**, section **Historique devis** :

| Statut | Signification |
| --- | --- |
| **Brouillon** | Devis créé, pas encore envoyé officiellement |
| **Envoyé** | Vous l'avez transmis au client (date enregistrée) |
| **Accepté** | Le client a validé — chantier planifiable |
| **Refusé** | Le client a décliné |
| **Annulé** | Annulation après acceptation (client a renoncé) |

### Actions courantes

| Action | Quand l'utiliser |
| --- | --- |
| **Marquer envoyé** | Après le premier envoi au client |
| **Accepté** / **Refusé** | Après la réponse du client (appel, WhatsApp…) |
| **Planifier le chantier** | Devis accepté — ajoute le chantier à votre agenda |
| **Client a annulé** | Le client renonce après avoir accepté |
| **Remettre en brouillon** | Corriger un devis avant re-envoi |

:::tip Relance client
Si le client n'a pas répondu : rouvrez l'historique → **Partager PDF** à nouveau, sans refaire toute la dictée.
:::

---

## Planifier le chantier

Quand un devis passe **Accepté**, ArtDevis tente de créer automatiquement une entrée dans **Mes Chantiers**.

Si ce n'est pas le cas : bouton **Planifier le chantier** sur la fiche client.

:::info Formule Pro
L'onglet **Mes Chantiers** nécessite la formule **Professionnel**.
:::

---

## Encaissement

ArtDevis **ne encaisse pas** les paiements en ligne (Phase 1). L'acompte et le solde se règlent hors app (virement, chèque, espèces). Vous émettez les **factures PDF** depuis l'app — voir [Chantiers et factures](/artdevis/guide-utilisateur/chantiers-et-factures).
